# rogueroute-gpx v13.1.1 — Clear stale Podman pods on start

A small fix for rootless Podman.

## Fixed

- `./rogueroute-gpx start`, `restart` and `update` failed under podman-compose with
  `Error: no pod with name or ID pod_rogueroute-gpx found` when the container from an earlier
  run outlived its pod. After pulling the image and before starting, the script now removes the
  previous `rogueroute-gpx` container and, on Podman, the `pod_rogueroute-gpx` pod, so Compose
  always starts from a clean state. Map data, `.env` and the map queue live on disk and are
  not affected.

## Upgrade

```bash
cd /opt/media-server/rogueroute-gpx
./rogueroute-gpx update
```

See [upgrading](../upgrading.md).
