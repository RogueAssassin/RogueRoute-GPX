# rogueroute-gpx v13.5.2 — Take built-in regions off the region list

In v13.5.0 and v13.5.1, **Delete files** in `/admin` took a region off the list only if it had
been added from **Add regions**. A built-in region (for example Europe or United States
mainland) stayed on the list as missing after its files were deleted, and nothing could remove it.

v13.5.2:

- **Delete files** deletes the files and takes the region off the list, built-in or added.
  A region without files shows **Remove from list**. The region being served is still refused.
- Removed built-in regions are kept under `hidden` in `OSRM_DATA_DIR/.rogueroute-gpx/regions.json`
  and stay off after restarts and updates. Adding one again from **Add regions** brings it back.
- `./rogueroute-gpx osm delete REGION --yes --remove` works for built-in regions too.

Everything else is as in [v13.5.1](v13.5.1.md).

## Upgrade

```bash
cd /opt/media-server/rogueroute-gpx
./rogueroute-gpx update
```

Then open the **Regions** tab of `/admin` and press **Remove from list** on any leftover region.
