# rogueroute-gpx v13.5.1 — Fix start and update after the v13.5.0 upgrade

After updating to v13.5.0, the first update moved `ADMIN_TOKEN` to `ADMIN_PASSWORD` and removed
it from `.env`. From then on `./rogueroute-gpx start`, `restart` and `update` stopped without a
message (exit code 1) before creating the container, so the website was down.

v13.5.1 fixes the `.env` tidy-up so a missing `ADMIN_TOKEN` line is fine, and CI now tests it.
Everything else is as in [v13.5.0](v13.5.0.md).

## Upgrade

If the container is missing, `update` fails in the same way, so first let the old script
through once by adding an empty `ADMIN_TOKEN=` line:

```bash
cd /opt/media-server/rogueroute-gpx
echo 'ADMIN_TOKEN=' >> .env
./rogueroute-gpx update
```

If the container is running (you have not run start, restart or update since v13.5.0), the
same two commands apply: the empty line is removed again by the update.
